# 人才分析工作台

从业务流程到数据工作台——一个纯前端的人力资源数据分析原型，上传三份 CSV 即可按需生成 HR 分析看板。

> **演示环境**：本页面为独立原型，全部数据均为虚构模拟数据，不涉及任何真实员工信息。

## 快速开始

1. 打开 [在线工作台](https://hesteright.github.io/talent-workbench-hes/hr-analytics-workbench/)，点击「体验模拟数据」，或按下方字段准备自己的 CSV。
2. 上传三份 CSV 数据（示例见 `demo-data/` 目录）：
   - `员工花名册.csv`：employee_id / department / job_level / tenure_months / age / monthly_salary / performance / is_key_position / is_manager
   - `人才流动数据.csv`：quarter / department / channel / hires / departures / avg_days_to_fill / cost_per_hire / retention_3m / retention_6m
   - `部门人效数据.csv`：quarter / department / headcount / revenue_per_capita / profit_per_capita / labor_cost / training_cost / satisfaction / perf_pass_rate
3. 勾选想看的分析模块，点击「生成分析看板」。

## 分析模块

| 模块 | 说明 | 数据源 |
| --- | --- | --- |
| 离职趋势 | 季度离职人数与离职／招聘比 | 人才流动数据 |
| 部门离职分析 | 部门离职人数与花名册人数之比 | 人才流动数据 + 花名册 |
| 司龄断档 | 在册员工司龄分段 | 花名册 + 人才流动数据 |
| 同期群留存 | 入职季度 × 留存月数热力图 | 人才流动数据 |
| 招聘漏斗 | 基于到岗人数及假设转化率的模拟漏斗 | 人才流动数据 |
| 招聘成本 | 各渠道总成本与人均成本 | 人才流动数据 |
| 渠道留存 | 3/6 月留存与衰减 | 人才流动数据 |
| 渠道性价比四象限 | 人均成本 × 留存 | 人才流动数据 |
| 部门人效 | 人均营收/利润 | 部门人效数据 |
| 人效趋势 | 人均利润季度走势 | 部门人效数据 |
| 成本结构 | 人力成本占比与瘦身 | 部门人效数据 |
| 规模经济性 | 人数 × 人均利润 | 部门人效数据 |
| 职级梯队 | 金字塔形态与断层 | 花名册 |
| 关键岗位备份 | 覆盖率与零备份清单 | 花名册 |
| 年龄司龄断层 | 各职级年龄/司龄 | 花名册 |
| 人才九宫格 | 绩效 × 潜力高潜识别 | 花名册 |
| 薪酬绩效关联 | 高薪低绩效/低薪高绩效 | 花名册 |
| 激励 ROI | 人均利润 / 人均成本 | 部门人效数据 |
| 薪资分位 | 关键岗被挖角风险 | 花名册 |
| 一页纸方案 | 面向 HRD 的加/砍建议 | 全部三份 |

## 数据安全与边界说明

- **纯前端运行**：所有 CSV 解析与计算均在浏览器本地完成，数据不会上传到任何服务器。
- **无外部依赖**：ECharts 已本地化（`vendor/echarts.min.js`），页面不调用任何外部 API、数据库或大模型接口。
- **模拟数据**：`demo-data/` 下的三份 CSV 均为虚构演示数据（公司、部门、员工均为模拟），仅用于展示分析流程。

## 部署

本仓库已配置为 GitHub Pages 静态站点，`index.html` 即为入口页。

## 指标说明

离职／招聘比反映同期离职与招聘人数的相对规模。计算标准离职率需各期平均在岗人数。招聘漏斗前序阶段及首月留存为示例估算。薪酬和组织建议用于实训情景讨论。
